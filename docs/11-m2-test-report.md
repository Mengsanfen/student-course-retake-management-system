## 2. 核心验证清单

| 场景 | 验证内容 |
| --- | --- |
| 重修资格 | 仅本人失败课程；未出分、60分及以上、他人选课、无效学期拒绝 |
| 有效唯一性 | 同课程学期有效申请唯一；驳回意见必填并可重提；并发只成功一份 |
| 双级审核 | 院系→校教务，禁止跳级和重复，教师/学生不能审核；并发只一条记录 |
| 权限范围 | 跨学生/院系拒绝，教师只读入本人班的申请和名册 |
| 开班 | 校级权限，教师/课程/学期合法，时间段有序且不超学期，班内不能自重叠 |
| 资源冲突 | 同学期教师或教室时间冲突拦截 |
| 选课资格 | 审核通过、班级开放、课程学期一致且未选课 |
| 课程冲突 | 同星期/周次/节次交集，区分在修与重修来源，返回说明和可用备选 |
| 时间边界 | 相邻不重叠节次、不同星期、周次不相交、边界周/节相交 |
| 名额并发 | 两学生抢最后一位，一成功一冲突；同一学生同时抢冲突课，仅一成功 |
| 班级维护 | 不能缩容至已选人数以下，暂停不删除选课/课表/名册 |
| 事务回滚 | 通知写入失败时选课与状态全部回滚 |
| 数据迁移 | 0001→0002不覆盖M1，元数据一致，快照源/目标版本不同时拒绝导入 |
| M1回归 | 认证/CSRF、材料权限、三级缓考审核、通知、数据同步保护等 |

## 4. 限制

双线程回归不等于100用户压力测试。当前固定周次区间，不含单双周、节假日调课、校区路程和真实教务同步；课表需要有效输入数据。教师和教室代码按当前字段标识匹配。规则判断以当次API说明返回，持久化校验日志属于M4。课程/学期/教师通用维护、退换班、收费、成绩与AI未实现。原有前端大包及测试适配器弃用警告仍待后续优化。
